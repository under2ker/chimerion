## Что это и для кого

CHIMERION помогает открывать ChatGPT, Claude и Gemini из России без VPN. Программа сама находит Smart DNS, проверяет, какие из них правда пускают к нейросетям, и подключает лучший в один клик. IP пользователя при этом не меняется, банки, Госуслуги и остальной интернет работают как раньше.

Главная идея: включил защиту и пользуешься. Подробности, полный список серверов и тонкие настройки лежат в панели управления, а главный экран показывает только важное.

## Безопасность

**Подписанные обновления.** Каждый архив собирается на серверах GitHub Actions из открытого кода, GitHub подтверждает его происхождение (attestation), а автор подписывает его ключом ECDSA P-256. Секретная часть ключа лежит только у автора. Без верной подписи программа обновление не ставит. Подпись проверяется одинаково на всех путях доставки: GitHub, зеркала и быстрый канал на Cloudflare R2.

**Три исхода проверки обновлений.** «Обновлений нет», «сервер обновлений недоступен» и «подпись неверна» показываются по-разному: при неверной подписи программа ничего не ставит и предупреждает красным.

**Откат неудачного обновления.** Если новая версия трижды не запустилась, программа сама возвращает прежнюю и больше эту версию не предлагает. В настройках есть кнопка «Вернуть версию» с понятным окном: что сохранится (настройки, серверы, подключение) и что пропадет. Резервная копия хранится в папке данных, а не рядом с программой, где ее мог бы подменить кто угодно.

**Подписанный каталог серверов.** Стартовый список серверов и наборы сайтов подписаны тем же ключом и имеют срок действия: не дольше 180 дней от даты обновления или не позже поля `expires`. Подменить список нельзя, а подсунуть старый подписанный список тоже: просроченный не принимается.

**Запуск без прав администратора.** Программа и автозапуск работают обычным процессом. Windows спрашивает права только когда нужно изменить или вернуть DNS. Раньше автозапуск давал права без запроса, а файл программы лежал там, где его могла подменить другая программа: это исправлено. Если отказаться в запросе прав, программа сама повторно не спрашивает, пока вы не нажмете «Подключить».

**Аккуратная работа с сетью.**
- DNS меняется только у физических адаптеров. VPN и виртуальные сети (Radmin VPN, Hamachi, ZeroTier) не трогаются.
- Перед сменой DNS программа проверяет, что данные для восстановления успешно сохранены.
- Если после подключения пропал интернет, настройки откатываются сами.
- В архив релиза входит аварийный `reset-dns.cmd`: он возвращает исходные DNS по резервной копии и убирает правила «Двух DNS».
- Закрыта утечка DNS через IPv6: если у сервера есть IPv6 и у компьютера есть IPv6-интернет, DNS ставится и для IPv6, иначе на время подключения IPv6 выключается там, где роутер раздает DNS по IPv6, и включается обратно при отключении. Аварийный сброс восстанавливает IPv6 и проверяет оба семейства.

**Устойчивая установка обновления.** Распакованный файл сверяется с архивом и должен быть программой Windows, отметка об обновлении пишется до замены файлов, при любом сбое прежняя программа остается на месте. На каждый шаг есть тест на обрыв.

**Безопасная передача скриптов.** Большие скрипты (например, для режима «Два DNS» с тысячами доменов) передаются в PowerShell проверяемым файлом, а не длинной командной строкой, которая упиралась бы в ограничение Windows.

**Безопасный поиск серверов.**
- Поиск не заходит на адреса локальной сети и на роутер, даже если на них ведет чужая ссылка.
- Сайты для взрослых, казино и ставок не открываются никогда.
- Страницы из выдачи поисковиков обходятся только по ссылкам с ключевыми словами.
- Каталоги всех публичных DNS мира (вроде public-dns.info) пропускаются: ни один их сервер не открывает нейросети.
- Внешние списки для обхода не принимают слишком широкие и локальные сети.

**Проверенные сторонние программы.** Дополнительные инструменты ставятся только из официальных релизов на GitHub и только при совпадении контрольной суммы. Свою копию, запущенную не через CHIMERION, программа не выключает и не подменяет.

**Предупреждения о среде, где программа не сработает.** Если PowerShell ограничен политикой (ConstrainedLanguage) или правила NRPT заданы групповой политикой, программа говорит об этом сразу, а не ломается молча.

## Приватность

- **Личные данные вырезаются.** Внешний IP, адреса локальной сети, город, провайдер, имя пользователя Windows и почта убираются из журнала, отчетов диагностики и черновиков для GitHub. Это делается всегда, без отдельной настройки.
- **Режим «Скрывать данные».** Две степени. «Только скрывать данные»: IP, город и провайдер на экране заменяются на «скрыто». «Стример мод»: дополнительно окна программы, меню, подсказки и меню трея не попадают на скриншоты, запись и демонстрацию экрана (OBS, Discord, Zoom, Teams, «Ножницы», Xbox Game Bar), а в миниатюрах на панели задач вместо окна значок.
- **Общая карта серверов только с согласия.** Согласие спрашивается один раз и меняется на вкладке «Приватность». Если вы согласились, раз в час уходят итоги проверок: адрес Smart DNS, его название, сервис и открылся ли он. Ваш IP сервер не хранит, сеть провайдера определяет сам по соединению. Код сервера открыт (`backend/crowd`).
- **Список сайтов не покидает компьютер.** Наблюдение за сайтами строится по кэшу DNS Windows, а наружу идет только имя сайта, который не открылся.
- **Cookie шифруются** ключом учетной записи Windows и уходят только на указанный сайт по HTTPS.
- **Понятные объяснения.** В настройках на вкладке «Приватность» для каждого режима написано, что именно скрывается, что заменяется метками, что уходит на общую карту и что видит ее сервер.

## Защита аккаунтов

Частая смена страны входа повышает риск блокировки аккаунта у сервисов. Поэтому программа держит страну под контролем.
- Помнит, из какой страны ChatGPT, Claude и Gemini обычно видят вас (страна и день за последние 30 дней, без адресов).
- Перед подключением к серверу, который выведет сервисы в другую страну, спрашивает. Согласие требует явной отметки «Понимаю, что аккаунт могут заблокировать». Если страна менялась за последние 14 дней, окно скажет об этом и покажет, из каких стран вы входили.
- Можно выбрать страну выхода: тогда подключение, замена и запасной сервер подбираются только с ней, а в «Рабочих» видны только такие серверы.
- Сама программа страну входа никогда не меняет. Если подходящей замены нет, она отключится, а не уведет вас в другую страну.
- Уведомление о смене страны приходит, только если смена подтвердилась на двух проверках подряд: разовый скачок туда и обратно не пугает.
- Репутация адреса выхода: программа смотрит оценку риска и черные списки. Серверы с адресом в черном списке или с высоким риском не попадают в лучшие, в замену и в запасные. Проверяются только адреса прокси серверов, ваш IP туда не уходит, итоги хранятся три дня.
- В диагностике есть пункт «Защита аккаунтов» с короткой сводкой «обычно X, сейчас Y», история стран под «Подробнее».

## Надежность и самовосстановление

- **Данные не пропадают молча.** Поврежденный файл настроек или списка серверов больше не заменяется пустым: программа говорит, что пропало, и сохраняет копию рядом. Файл, ненадолго занятый антивирусом, не принимается за поврежденный. Если `settings.json` занят, настройки сохраняются, когда файл освободится, а настройки, которые не удалось прочитать при запуске, не затираются значениями по умолчанию.
- **Подключение переживает перезагрузку.** При выключении и перезагрузке Windows подключение не снимается: DNS остается на адаптере, и после загрузки CHIMERION продолжает с того же сервера. Сеть после загрузки поднимается не сразу, поэтому программа ждет ее до полутора минут.
- **Сброс DNS после обновления Windows или чужой программы** не проблема: подключение возвращается без вопросов, а если прежний сервер молчит, берется следующий по стабильности.
- **Запасной сервер.** Вместе с выбранным в Windows прописывается второй рабочий, всегда с той же страной выхода. Если основной замолчит, Windows за секунды перейдет на запасной, нейросети не пропадут. Если такого сервера нет, запасной не ставится. Выключается в настройках.
- **История сетевых изменений.** Что программа меняла в сети, когда и почему (ваше действие, сторож, запуск Windows, режим, автоподбор): одно окно в «Диагностике».
- **Отмена действий.** Удаление, автоочистка, добавление сервера, подключение, переключение, отключение, избранное, сохранение настроек, очистка журнала и пропуск версии отменяются кнопкой «Отменить» или Ctrl+Z.
- **Сервер, к которому вы подключены, удалить нельзя.** Если ручное переключение не удалось, программа возвращает прежний сервер.
- **Корректный выход.** Программа не зависает в процессах после закрытия, при выходе можно оставить работать DNS и дополнительные инструменты, а можно выключить все и вернуть DNS как было. Окно выхода объясняет разницу в одну-две строки.
- **Защита от сбоя посреди изменения.** Если программу закрыть во время подключения, выключенный IPv6 не остается выключенным: он включается обратно, а если Windows не дает это сделать, программа объясняет, как включить вручную.
- **Устойчивость без GitHub.** Обновления, списки серверов, наборы сайтов и файлы сторонних программ берутся через зеркала, если GitHub недоступен. Если загрузка замирает из-за замедления одного из каналов, архив докачивается маленькими кусками, каждый новым соединением.
- **Второй запуск** открывает уже запущенную копию, а не показывает ошибку.

## Сторож подключения

Пока вы подключены, программа следит за DNS и сервисами.
- Если DNS сбросила другая программа или Windows, подключение возвращается.
- Если сервер перестал отвечать, программа переключается на следующий по стабильности, а при равенстве на избранный. Сначала берутся серверы с той же страной выхода.
- Пока сети нет совсем (сон, загрузка, смена Wi-Fi), сторож ждет и неудачей это не считает.
- Каждый адаптер проверяется отдельно: сброс DNS на одном из нескольких не остается незамеченным.
- В фоне проверяется, открываются ли ChatGPT, Claude и Gemini через текущий сервер. Если сервис не открылся несколько проверок подряд, приходит уведомление с причиной: сервер перестал подменять адреса, прокси попал под блокировку, сервер не отвечает или DNS-сервер молчит, а Windows ушла на запасной. Когда сервис снова открывается, тоже приходит уведомление.
- Избранные серверы тоже под присмотром.
- Настройка «Программа может сама переходить на другой сервер»: если выключить, программа никогда не меняет сервер без вас, а при падении сервера присылает только уведомление.
- Если сторонний VPN сам переписывает DNS, сторож не спорит с ним: не возвращает DNS и не меняет сервер, пока VPN работает. Если DNS сбрасывается снова и снова, сторож решает, что его меняет другая программа, перестает спорить и подсказывает, что делать.
- Каждое уведомление подписано функцией, которая его присылает: «Проверка сайтов», «Мониторинг сервисов», «Сторож», «Защита аккаунтов» и другие.

## Проверка серверов

- **Доступ засчитывается по живому ответу сервиса.** Страница защиты, редирект или ошибка сервера доступом не считаются. Ответ должен прийти от самого сервиса: проверяется API и сайт.
- **Подмена адресов проверяется сравнением** с честным DoH (по умолчанию Cloudflare, запасной Google), которому провайдер не может подменить ответ. Адрес, принадлежащий самому сервису, подменой не считается.
- **Gemini без ключа API** отвечает одинаково из любого региона, поэтому доступ подтверждается подменой адреса и проверкой сайта. Если подтвердить нельзя, программа так и пишет: «сайт не подтвержден», а не «не открывается».
- **Каждый сервис оценивается отдельно.** Стабильность считается по каждому сервису, а лучшие серверы выбираются для ChatGPT, Claude, Gemini и для всех трех сразу. Если один сервер лучший для всех, показывается одна строка вместо четырех.
- **Причины вместо «не работает».** У нерабочего или частично рабочего сервера подсказка говорит, почему: обычный DNS без подмены, регион закрыт, нет ответа DNS, таймаут, капча.
- **Тест скорости DNS** отдельно от пинга и доступа: медиана, медленные ответы, запросов в секунду.
- **Автоподбор.** Кнопка на главном экране пробует до пяти лучших серверов и остается на первом, через который открываются нейросети; страну выхода не меняет.
- **Прозрачная оценка.** В подсказке видны доступность, совместимость с сервисами, стабильность, задержка, свежесть проверки и уверенность. Лучший сервер выбирается с учетом уверенности: один удачный замер не делает сервер лучшим.
- **Режимы перепроверки:** обычная, глубокая (три прохода, чтобы отсеять случайные сбои) и только по одному сервису. Порядок «Сначала лучшие для Claude» выстраивает таблицу по одному сервису.
- **Страна выхода у каждого сервера.** Строка «ИИ видят вас из»: некоторые Smart DNS отдают адрес в России, а трафик выпускают через другую страну, и это видно.
- **Страна определяется по нескольким базам** и побеждает большинство. В подсказке видно, что ответила каждая база.
- **Ложные тревоги отсеяны.** Если во время проверки пропал интернет или включен VPN, результаты не портятся: серверы не помечаются нерабочими и не уходят в мусор. Капча Google помечается отдельно, а не как блокировка региона.
- **Тест утечки DNS:** видно, какие резолверы на самом деле отвечают. Если у них разные владельцы, показывается предупреждение.
- **Автоочистка.** Серверы, которые ни разу не заработали за три дня, убираются, но не сразу после входа в Windows, и сотни строк удаляются одним пакетом.
- **Общая карта подсказывает серверы,** которые работают у других пользователей вашей сети, а бот @CHIMERIONDNS_BOT по команде /dns показывает, какие серверы работают сейчас.

## Оптимизация

- **Быстрое включение и выключение.** Проверка доступа к нейросетям после смены DNS идет в фоне и не держит переключатель, при выключении DNS сети возвращаются сразу, без ожидания проверки до 20 секунд. Перед подключением берется свежая проверка сети, если она уже есть. Все это ускорило включение и выключение в несколько раз.
- **Меньше лишних запросов.** Фоновая проверка сервисов облегченная (по одному запросу к каждому сервису), полная раз в час. При запуске перепроверяются только серверы, которые не проверялись больше 3 часов.
- **Защита списка от раздувания.** Страница с сотнями адресов пропускается целиком, считаются разные серверы, а не строки (у файла GeoHideDNS тысячи строк, но около двадцати адресов), у одного поиска есть предел числа новых серверов, а раздутый список чистится сам при запуске. Рабочие, избранные и подключенный остаются всегда. Раньше один поиск мог набрать больше 100 тысяч адресов, и проверка шла минутами.
- **Быстрое отключение.** DNS-адреса всех адаптеров запрашиваются одной командой, а не отдельной на каждый.
- **Компактный журнал.** Подробная запись для разбора сбоев пишется целиком только при сбое или медленной операции (дольше 2 секунд), иначе одной строкой или совсем без записи. Размер журнала упал с 10 МБ в день в разы. Журнал хранится 3 дня, в отчет идут последние 4000 строк.
- **Системный DNS читается напрямую** из сетевых интерфейсов, проверка подключения стала быстрее на секунду. Блок «Проверка подключения» перестраивается только при новом результате, список серверов пишется на диск только при изменении, флаги стран декодируются один раз.
- **Копирование без сбоев.** Буфер обмена часто держат другие программы, поэтому копирование повторяется и обходит их, а кнопка «Сохранить отчет» дает запасной путь файлом.
- **Облегченное устройство окон.** Окна строятся по содержимому, подстраиваются под экран и не выходят за его край, тяжелые элементы пересчитываются только при смене размера, а анимации выключаются, если они отключены в Windows.

## Асинхронность и параллельность

- **Вся работа с сетью асинхронная** (`async`/`await`): проверки серверов, поиск, обновления, диагностика и фоновые проверки не блокируют окно. Пока идет долгая операция, интерфейс остается живым.
- **Отмена и таймауты везде.** Операции принимают токен отмены и имеют предел времени. Каждая страница поиска ограничена по времени (45 секунд), медленная страница (дольше 10 секунд) отмечается в журнале, но не останавливает остальной поиск.
- **Управляемая параллельность.** Серверы проверяются пачками с заданным числом одновременных запросов (настройка), запросы к поисковикам идут параллельно не больше трех сразу, а запросы к отдельным поисковикам идут бережно, с паузами и с учетом их лимитов.
- **Поиск не ждет самую медленную страницу.** Ссылки найденных страниц сразу уходят в работу, а прогресс и время поиска обновляются каждую секунду.
- **Все выключается одновременно.** При выходе дополнительные инструменты останавливаются параллельно и не дольше 6 секунд в сумме, чтобы выход не висел.
- **Трассировка операций.** Каждая операция в подробном журнале связана номером сеанса и родителя, с длительностью и итогом. По присланному отчету видно, где и что сломалось, не прося пользователя повторять шаги.
- **Защита от гонок.** Решение сторожа, пока шла проверка, не применяется, если вы за это время сами подключились или отключились. Копия данных для тестов отключает автоматическое изменение настоящего DNS компьютера.

## Smart DNS и режим «Два DNS»

- **Smart DNS для нейросетей** подключается в один клик, исходные настройки сохраняются, отключение возвращает все как было. Поддерживаются обычный DNS и DoH.
- **Два DNS.** Нейросети идут через Smart DNS, весь остальной интернет через обычный DNS. Банки, Госуслуги и российские сайты не замечают подмены. Общий DNS можно оставить свой или выбрать из готовых, а программа покажет, какой лучше открывает заблокированное и не ломает российские сайты. Есть схема «куда идут запросы нейросетей и остальных сайтов» без обещаний результата.
- **Предупреждения.** Если общий DNS в «Двух DNS» совпадает со Smart DNS, программа предупредит: тогда через Smart DNS идет весь интернет, и часть сайтов может не открываться.
- **Что открывает сервер.** У каждого набора видно, подменяет ли его подключенный Smart DNS.
- **Для разработчиков:** наборы для Cursor, GitHub Copilot, Windsurf, JetBrains AI и других инструментов с ИИ включаются одной кнопкой. Проверяется WSL: без DNS-туннеля Claude Code и pip внутри Linux идут мимо Smart DNS, это включается одной кнопкой, прежний `.wslconfig` сохраняется рядом.
- **Помехи.** После подключения программа ищет то, что мешает: включенный VPN, безопасный DNS в Chrome, Edge, Яндекс Браузере, Brave и Firefox, прокси Windows, записи в `hosts`, чужие DNS на других адаптерах, DNS по IPv6 на сетевой карте. Показывает, что отключить, а часть можно исправить прямо из отчета.
- **Телефон.** Тот же Smart DNS можно поставить на iPhone (QR-код с профилем и сохранение профиля файлом) и Android 9 и новее («Частный DNS»), нужен сервер с DoH. Отдельное приложение для этого не требуется.

## Дополнительные инструменты

Рядом с основной задачей CHIMERION управляет двумя открытыми программами сторонних авторов: ускорением Telegram Desktop (TG WS Proxy) и обходом замедления YouTube и Discord (zapret-discord-youtube). Ставятся из официальных релизов с проверкой контрольной суммы, запускаются, выключаются и обновляются из окна «Telegram и YouTube», а чтобы не спрашивать права Windows при каждом включении, программа один раз создает два задания Планировщика: запускать их может только текущий пользователь, а менять только администратор. Эта возможность новая (версия 0.1.67) и проверена пока только автоматическими тестами. Готовые наборы сайтов по разделам, большие списки и свои сайты собираются в окне «Сайты для обхода»; свои сайты проверяются сразу, а закрытые для России можно одной кнопкой отправить в Smart DNS. Если рядом стоит чужая служба или две копии мешают друг другу, программа об этом говорит.

## Диагностика и помощь

- **Одна кнопка собирает все проверки в отчет:** подключение, доступ к сервисам, страна выхода и ее репутация, помехи, состояние дополнительных программ, обновления.
- **Проблемы собраны сверху,** остальное по разделам, у каждой проблемы есть «Подробнее» и кнопка, которая ее исправляет.
- **Проверка любого сайта.** Программа скажет, виноват DNS, провайдер или сам сайт, и что поможет. Если DNS системы подменяет адрес сайта своим прокси, это тоже распознается.
- **Отчет можно скопировать или сохранить файлом,** личные данные из него убраны. Есть кнопка «Сообщить о проблеме»: открывается черновик на GitHub, а полный отчет остается в буфере.
- **Мастер «Не открывается».** Шаг за шагом находит, почему не открывается нейросеть или сайт.
- **Под наблюдением.** Фоновая проверка ваших сайтов с уведомлением, если какой-то перестал открываться. В уведомлении причина: блокирует провайдер, лежит у всех, закрыт для России или Smart DNS перестал его подменять.
- **Журнал в отдельном окне.** События за 3 дня с фильтрами, поиском, копированием всего или отдельных строк, сохранением в файл, подсказками по клавишам. Одинаковые записи подряд склеиваются в одну со счетчиком.
- **Окно «Помощь» с вкладками** «Не открывается», «Под наблюдением» и «На телефоне».

## Интерфейс

- **Главный экран.** Большой переключатель защиты, состояние нейросетей, переключатели дополнительных программ, три лучших сервера и последние события. Если какая-то нейросеть не открывается, это видно сверху, а кнопка «Почему?» объяснит причину.
- **Панель управления** с полным списком серверов, поиском, фильтрами «Рабочие / Все / Избранные», проверкой подключения и тонкими настройками. Таблица показывает столько колонок, сколько помещается, колонки не наезжают друг на друга, а подключенный сервер всегда первый.
- **Режимы.** «Только ИИ», «Все сразу», «Игры», «Все выключить» одним щелчком, из окна, трея или сочетанием Ctrl+1…4. Перед включением видно, что именно изменится по каждой части.
- **Компактный вид** для узкого окна: кнопка подключения, три плитки нейросетей, переключатели дополнительных программ и список рабочих серверов. Меню панели можно свернуть.
- **Трей.** Статус подключения, пинг, стабильность, доступность сервисов, переключение на лучший сервер и режимов.
- **Две темы и свои цвета.** Светлая и темная темы меняют все окна сразу, акцент на светлом фоне программа сама делает темнее, чтобы текст читался. Есть готовые наборы цветов и свои.
- **Русский и английский язык.** Переключатель в настройках, переведены все окна, уведомления и подсказки.
- **Движение с умом.** Новый мягкий переключатель с пружинным бегунком, который доезжает, растягивается на ходу и перетаскивается. Плавная смена текстов и цветов, оживающие иконки, понятные состояния «Включаю защиту…» и «Выключаю защиту…». Если анимации отключены в Windows, все стоит на месте.
- **Читаемость.** Второстепенный текст ярче и крупнее, пояснения короткие, у каждой плитки и кнопки подсказка, а там, где нужно что-то выбрать, есть метка «рекомендуем» и кнопки «Рекомендуемые», «Выбрать все» и «Снять все».
- **Отчет в один клик.** Проверка, сохранение на рабочий стол, копирование и показ файла одной кнопкой; в отчете действия пользователя, последние ошибки программы и журнал без личных данных.
- **График качества сервера.** Время ответа и проверки без ответа за 14 дней, выводы словами (например, «чаще всего сбои вечером») по истории, которую программа уже хранит.
- **Перенос на другой компьютер.** Экспорт и импорт настроек и избранных серверов одним файлом: только безопасные поля, чужой файл проверяется (размер, пределы чисел, адреса серверов), перед применением видно, что изменится, и импорт можно отменить.
- **Окна всегда по размеру.** Окна открываются в размере, в котором видно все содержимое, подстраивают высоту под страницу, не выходят за край экрана и закрываются клавишей Esc.
- **Доступность.** Управление с клавиатуры, видимое выделение фокуса, подписи у всех иконок.
- **Фирменный стиль:** знак из трех полос, графитовая палитра с лаймовым акцентом, векторные иконки вместо символов шрифта, логотипы ChatGPT, Claude, Gemini, YouTube, Discord и Telegram.

## Обновления и доставка

- **Обновление прямо из программы** одной кнопкой: скачивание, проверка суммы SHA-256 и подписи, замена файла, перезапуск за 3 секунды, подключение DNS сохраняется. Окно показывает версию, откуда она, описание по разделам, этапы, проценты, размер, скорость и оставшееся время.
- **Автоматическая проверка:** через 10 секунд после запуска и потом каждые 6 часов, а когда программа в трее, приходит уведомление. Карточка обновления внизу меню подсвечивается, когда вышла новая версия, а проверку можно выключить.
- **Два канала.** Срочные исправления выходят через быстрый канал на Cloudflare R2, большие релизы через GitHub, программа берет более новую версию. Если GitHub недоступен, ответ дает второй канал.
- **Новая версия встает под именем `CHIMERION.exe`.** Ярлыки, меню «Пуск» и автозапуск переходят на нее сами.
- **Сайт [chimerion.dev](https://chimerion.dev).** Описание, сравнение с VPN, как начать, частые вопросы, скриншоты с плавным увеличением, автоматическая подстановка актуальной версии с проверкой адреса скачивания.
- **Telegram.** Канал [@chimeriondns](https://t.me/chimeriondns) с пометкой каждого поста (крупное обновление, обновление, хотфикс), чат с темами «Помощь», «Баг-репорты», «Рабочие DNS» и «Идеи».

## Качество и проверка

- **Больше 540 автоматических тестов**, в том числе проверки репозитория, которые идут и в CI (подписи каталогов, секреты, лишние буквы и тире в текстах, версия в CHANGELOG), сборка с предупреждениями как ошибками и поиск уязвимых пакетов. Основные группы: подписи и сроки каталога, откат DNS, сценарии аварийного завершения и сбоев сети (эмуляция сети и PowerShell), разбор DNS-ответов и DoH, приватность отчетов, защита списка серверов, оценка серверов, тексты главного экрана, журнал, режимы, диагностика, задания Планировщика, трассировка операций.
- **Сборка без предупреждений компилятора,** а перед каждым коммитом все тесты зеленые.
- **Проверка интерфейса по снимкам.** Для каждого окна снимаются размеры 1000, 1366, 1600 и 1920 пикселей, компактный вид, свернутое меню, светлая тема и английский язык: ничего не наезжает, нет горизонтальной прокрутки и пустых мест. Для снимков и тестов используется отдельная копия данных с выдуманными адресами, она не трогает настоящий DNS.
