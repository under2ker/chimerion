# DNEX — переключатель DNS для доступа к ИИ

WPF-приложение (.NET 8) для Windows: собирает DNS-серверы из интернета, проверяет их и переключает DNS системы в один клик.

## Сборка
1. Установите .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
2. В папке проекта:
   ```
   dotnet build -c Release
   dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
   ```
   Готовый `DNEX.exe` — в `bin\Release\net8.0-windows\win-x64\publish\`. Запускается с правами администратора (нужно для смены DNS).

## Возможности
- **Глубокий парсер**: стартовые страницы (сайты, статьи, 4PDA, Telegram `t.me/s/…`, raw-файлы GitHub) + автопоиск через DuckDuckGo/Bing; обход ссылок по ключевым словам на заданную глубину; листание тем форумов и каналов; кодировки UTF-8 / windows-1251.
- **Источник у каждого сервера**: колонка «Источник» с кнопкой 🔗 открывает страницу, где сервер найден.
- **Проверка** для ChatGPT, Claude, Gemini: ответ сервера и пинг, подмена адреса (сравнение с эталонным DoH), HTTPS-запрос к API через полученный IP с проверкой сертификата и маркеров «регион не поддерживается». Ведётся статистика стабильности.
- **Поиск и фильтр** по имени, IP, DoH, источнику, сервисам и статусу.
- **Переключение**: обычный DNS или DoH (Windows 11), резервная копия исходных настроек и возврат одной кнопкой. Двойной клик по строке — применить.

## Настройки
Кнопка «Папка данных» открывает `%AppData%\DNEX`:
- `settings.json` — источники (`sources`), глубина/лимиты обхода, поисковые запросы (`discoveryQueries`), ключевые слова ссылок, сервисы и признаки блокировки (`targets`), исключённые IP, `hostCookies`.
- `servers.json` — список серверов и результаты проверок.

После правки нажмите «Перечитать настройки».

### Сайты с авторизацией (4PDA)
Если без входа видно не всё, добавьте Cookie из браузера, где вы залогинены:
```json
"hostCookies": { "4pda.to": "member_id=...; pass_hash=...; ..." }
```
(DevTools → Network → любой запрос к 4pda.to → заголовок Cookie). Это данные входа в ваш аккаунт — не передавайте файл другим.

## Безопасность
- Программа запускается **без прав администратора**. UAC запрашивается только на смену/возврат DNS; парсер чужих сайтов никогда не работает от администратора.
- PowerShell вызывается по полному системному пути, скрипт передаётся через `-EncodedCommand` (без временных .ps1). IP проверяются, DoH-адрес экранируется.
- Парсер не обращается к localhost, роутеру и адресам локальной сети (защита от ссылок-ловушек), обрабатывает переадресации сам и отправляет Cookie только своему домену и только по HTTPS.
- Cookie в `settings.json` автоматически шифруются ключом вашей учётной записи Windows (DPAPI).
- Регулярные выражения с тайм-аутом, размер страниц и ответов ограничен, DNS-ответы разбираются с проверкой границ.
- HTTPS-проверка серверов проверяет сертификат сервиса: прокси с поддельным сертификатом не засчитывается как рабочий.

- Отключение ищет адаптеры по GUID (номер интерфейса может смениться), сбрасывает все адаптеры, где остались адреса DNEX, удаляет только свои записи DoH и сверяет результат.
- После подключения проверяется, что интернет жив; если нет — автоматический откат. Сторож отключает при 3 неудачах подряд.
- Только один экземпляр программы; значения в settings.json проверяются при загрузке.
- Для блока «До / После» внешний IP запрашивается у ipinfo.io по HTTPS (без ключей и данных пользователя).

## Ограничения
- Обычный DNS (порт 53) провайдер может перехватывать — предпочитайте серверы с DoH.
- Если в сети есть IPv6-DNS от роутера, он может обходить выбранный сервер.
- Маркеры блокировки сервисов эвристические, их можно поправить в `targets`.
- Доступ к ИИ-сервисам в обход их гео-ограничений нарушает их условия использования; возможна блокировка аккаунта.
