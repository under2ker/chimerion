# История изменений

## 0.1.7

- Запросы к поисковикам при поиске новых серверов идут параллельно, не больше трех сразу.
- Флаги стран декодируются один раз и переиспользуются.

## 0.1.6

- Поиск новых серверов больше не ждет самую медленную страницу. Ссылки найденных страниц сразу уходят в работу.
- Медленные страницы (дольше 10 секунд) отмечаются в журнале.

## 0.1.5

- Таблица показывает для подключенного сервера результат проверки подключения: ИИ-сервисы, которые не открылись, отмечаются как не работающие.

## 0.1.4

- Проверка подключения больше не показывает сервисы доступными, когда DNEX отключена: каждая проверка идет со своим соединением.

## 0.1.3

- Логотипы ChatGPT, Claude и Gemini в блоке «Проверка подключения» и в списке сервисов.
- Поиск новых серверов показывает, сколько времени он идет: строка прогресса обновляется каждую секунду, даже если страницы загружаются медленно.

## 0.1.2

- Подключенный сервер всегда первый в таблице, даже если отсортировать ее по другой колонке.

## 0.1.1

- Новые серверы появляются в таблице с анимацией: строка проявляется и поднимается снизу.
- Удаляемая строка плавно гаснет.
- Полоса поиска больше не появляется в шапке. Прогресс остается в панели инструментов.

## 0.1.0

Первая публичная версия.

### Проверка серверов и сервисов

- Доступ к ChatGPT, Claude и Gemini засчитывается только по ожидаемому ответу API. Страница защиты, редирект или ошибка сервера доступом не считаются.
- Тот же критерий используется в таблице серверов и в блоке «Проверка подключения», поэтому результаты совпадают.
- Для каждого сервиса видно, через какую страну идет доступ. Если сервис открывается напрямую, страна не показывается.

### Локация

- Страна и город DNS-сервера определяются по двум IP-базам: ipinfo.io и ipwho.is. Если базы расходятся, рядом появляется предупреждение.
- Флаги стран скачиваются один раз и хранятся в кэше.

### Трей

- Меню показывает статус подключения, пинг, стабильность и доступность трех сервисов.
- Пункт «Переключить на лучший» подключает самый надежный из рабочих серверов.
- Доступность сервисов обновляется при запуске, при подключении и через заданный интервал.

### Окно

- Шапка показывает пинг, стабильность и число доступных сервисов. При узком окне эти блоки переходят на вторую строку.
- Значок связи показывает пинг столбиками: их число и цвет зависят от значения. Значок есть в шапке, в таблице и в меню трея.
- Компактный вид: отдельное окно с кнопкой подключения, статистикой и списком рабочих серверов.
- Колонки таблицы скрываются по мере сужения окна, чтобы главное не обрезалось.
- Окно настроек: эталонный DoH, таймаут, число одновременных проверок, интервалы трея и сторожа, папка данных.

### Исправления

- Подсветка кнопок и вкладок покрывает всю кнопку, а не только текст.
- Галочки центрированы.
- Тексты интерфейса приведены к единому стилю.

### Известные ограничения

- Локация определяется по IP-базам, а не по физическому месту. Для DoH-серверов за anycast-адресами она может показывать ближайший узел.
- Признаки блокировки сервисов определяются эвристически. Их можно поправить в `settings.json`.
- Встроенный каталог серверов устаревает: адреса сервисов меняются.
- Проверка работает только по IPv4.
- Программа не подписана цифровой подписью, Windows SmartScreen может показать предупреждение.
- Версии для Android пока нет. Перенос уже идет, выйдет отдельным релизом.
