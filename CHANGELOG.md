# История изменений

## 0.1.25

**DNEX теперь называется CHIMERION.** Это тот же проект. Установленная DNEX обновится сама, настройки, список серверов, подключение и автозапуск остаются на месте. Репозиторий переехал на github.com/under2ker/chimerion, старые ссылки перенаправляются.

Новое оформление
- Свой знак из трех полос, надпись CHIMERION, новая иконка программы. Иконка остается четкой даже в 16 пикселях.
- Графитовая палитра с белым текстом и лаймовым акцентом. Иконки во всей программе векторные, вместо символов шрифта.
- Светлая тема. Переключается в настройках, все окна меняются сразу. Акцент на белом фоне программа сама делает темнее, чтобы текст читался.
- Свои цвета интерфейса: семь готовых наборов и отдельный цвет для кнопок, галочек, вкладок, выделения, меню и меток. Цвет можно выбрать из палитры или ввести кодом. Знак в заголовке, значках окон и трее перекрашивается вместе с акцентом.
- Английский язык. Переключатель «Русский | English» в шапке настроек.

Два DNS и обход
- «Два DNS»: нейросети идут через Smart DNS, остальной интернет через обычный DNS. Окно сделано заново, на двух вкладках.
- «Сайты для обхода» для zapret: 38 готовых наборов по разделам (соцсети, видео, графика, разработка, игры, ИИ и другие), большой список заблокированного от Re:filter и свои сайты. Свои сайты программа проверяет сама и подсказывает, поможет ли им zapret или их лучше отправить в Smart DNS.
- Подбор стратегии zapret проверяет и ваши сайты, а не только YouTube и Discord. Лучшую можно включить одной кнопкой или сразу после подбора.
- Обход по адресам (IPSet) с выбором списка: сборка zapret, Re:filter, eduard256 или CDN и хостинги.

Проверка и подсказки
- «Диагностика»: все проверки в одном отчете, проверка любого сайта и кнопки, которые сами исправляют найденное. Отчет можно отправить на GitHub, личные данные из него убираются.
- Метки «рекомендуем» и короткие подсказки «что нажать» во всех окнах. Кнопки «Рекомендуемые», «Выбрать все» и «Снять все» там, где раньше все отмечалось руками.
- В шапке видно, сколько сайтов и сетей сейчас идет через обход.
- Предупреждение, если сервер начал выпускать трафик через другую страну.
- Стартовый список проверенных серверов приходит с GitHub, подписанный, новичку не нужно ждать поиск.
- В таблице меню «Выделить»: все нерабочие, частично рабочие, рабочие.

Надежность
- Обновление можно откатить: если новая версия трижды не запустилась, программа сама вернет прежнюю, а в настройках есть кнопка «Вернуть версию». Обновления подписаны, архив собирается на GitHub Actions.
- При выходе можно оставить работать не только DNS, но и обход zapret и ускорение Telegram.
- Программа больше не зависает в процессах после закрытия.
- Окна не выходят за край экрана, Esc закрывает любое окно.

Исправлено
- Ошибка при прокрутке колесом над текстом. Прокрутка стала плавной и не дергается при быстром листании.
- Сервер, добавленный вручную, больше не исчезал после проверки.
- Подменю в меню не раскрывались.
- Таблица серверов пропадала в низком окне, текст в ячейках обрезался, источник занимал полколонки.
- Уведомления перекрывали кнопки, затирали друг друга и пропадали, когда окно свернуто.
- Меню трея: пункты выходили за край, подсветка стояла криво, подменю открывалось с зазором.
- Надпись на основной кнопке и значок загрузки терялись на ее заливке.
- Еще десятки мелких правок по вниманию к деталям: выравнивание, подписи, переводы, контраст.

## 0.1.24

- Обновление прямо из программы. В окне новой версии кнопка «Обновить» скачивает архив из релиза, сверяет контрольную сумму SHA-256 и ставит новый DNEX.exe на место старого. Потом программа предлагает перезапуск. Подключение DNS при перезапуске сохраняется. Если что-то пошло не так, программа остается прежней, а окно пишет причину и предлагает страницу релиза.
- Telegram и YouTube. Кнопка внизу окна и пункты в трее включают две сторонние программы с открытым кодом: TG WS Proxy (ускорение Telegram Desktop) и zapret-discord-youtube (обход замедления YouTube и Discord). DNEX ставит их официальные релизы с GitHub после проверки контрольной суммы, запускает, выключает и обновляет. Для zapret есть выбор стратегии и обход для игр, для Telegram кнопка «Подключить Telegram». Свою копию TG WS Proxy, запущенную не через DNEX, программа не выключает.
- Все сообщения теперь в стиле программы. Белые системные окна Windows (ошибка, «DNEX уже запущена», подтверждения) заменены темными, со значком и понятным заголовком. У окон одинаковые заголовки «DNEX · …» и значок программы.
- Заголовок окна выхода больше не обрезается, длинное название сервера переносится.
- В окне обновления описание версии показано по разделам и пунктам, а не сплошным текстом.
- Пункты меню трея выровнены по строкам статуса.
- «Удалить 3 сервера» вместо «Удалить 3 серверов».

## 0.1.23

- Исправлено черное окно после запуска вместе с Windows. Раньше окно создавалось сразу при входе в систему, пока видеодрайвер еще не был готов, и оставалось черным до закрытия. Теперь при автозапуске окно не создается вовсе: работает трей, подключение и сторож. Окно появляется, когда вы открываете его из трея.
- Окно обновления, которое приходит, пока программа в трее, открывается по центру экрана и видно в панели задач.

## 0.1.22

- Автозапуск вместе с Windows. Галочка в настройках создает задание в Планировщике: программа стартует при входе в систему, сразу в трее и с правами администратора. Права Windows спросит один раз, когда включаете автозапуск.
- После загрузки DNEX сама проверяет подключение. Если DNS был включен, а после перезагрузки его сбросило обновление Windows, другой адаптер или чужая программа, подключение возвращается без вопросов. Сеть после загрузки поднимается не сразу, поэтому программа ждет ее до полутора минут. Если прежний сервер не отвечает, берется следующий по стабильности.
- Строка «ИИ видят вас из»: страна и город, с которых ChatGPT, Claude и Gemini на самом деле видят подключение. Некоторые Smart DNS отдают адрес в России, а трафик выпускают через другую страну. Раньше это было не видно, теперь страна выхода показывается для каждого сервиса и у каждого сервера в таблице.
- Избранные серверы стоят в таблице сразу под подключенным.
- Перепроверка с выбором: обычная, глубокая (три прохода, чтобы отсеять случайные сбои) и только по одному сервису. Проверка только Claude меняет результаты Claude и не трогает остальные.
- Порядок «Сначала лучшие для Claude» (или ChatGPT, Gemini): таблица выстраивается по одному сервису. Плашка над таблицей показывает режим, крестик возвращает обычный порядок.
- Версия программы и кнопка «Проверить обновление» переехали в нижнюю строку окна.
- Проверка обновления надежнее. Если GitHub API не отвечает или упирается в лимит, программа смотрит ленту релизов, а потом страницу последнего релиза. При неудаче пишет причину.
- Поиск серверов глубже: больше страниц и источников, поиск по GitHub-репозиториям, ссылки из выдачи Bing раскрываются в настоящие адреса.
- Поиск больше не уходит на посторонние сайты. Страницы из выдачи поисковиков обходятся только по ссылкам с ключевыми словами, а сайты для взрослых, казино и ставки отсекаются всегда.
- Один запрос к сайту сервиса на адрес прокси за всю проверку. У многих серверов один прокси, и частые одинаковые запросы заставляли Google показывать капчу. Капча теперь помечается отдельно, желтым, а не как блокировка региона.
- Если во время проверки пропал интернет, результаты не портятся: серверы не помечаются нерабочими и не удаляются.
- Серверы, которые ни разу не заработали за три дня, убираются при чистке. Сотни строк удаляются одним пакетом, программа больше не замирает.
- На весь экран окно больше не заходит под панель задач, нижняя строка видна.
- Исправлен редкий сбой при закрытии окна с отключением DNS.
- Ссылки из программы открываются в обычном браузере, даже когда DNEX запущена с правами администратора.

## 0.1.19

- Над списком серверов появился блок «Лучшие по стабильности»: отдельно лучший сервер для ChatGPT, для Claude, для Gemini и для всех трех сразу. Щелчок по строке выбирает сервер в списке. В таблице у такого сервера бейдж «лучший для всех» или «лучший: Claude».
- Стабильность считается по каждому сервису отдельно (счет начинается с этой версии).
- Серверы можно добавлять в избранное: звездочка в строке, пункт в меню строки и вкладка «Избранные».
- Проверка доступа переделана по живым ответам сервисов. Доступ засчитывается, только если ответ пришел от самого сервиса. Дополнительно проверяется сайт: если claude.ai уводит на страницу «недоступно в регионе», а Google показывает капчу на адресе прокси, сервис считается закрытым.
- Gemini без ключа отвечает одинаково и из закрытого региона, и через прокси. Теперь для него доступ подтверждается подменой адреса и проверкой сайта gemini.google.com.
- Адрес, который принадлежит самому сервису (сети Google, Anthropic, Cloudflare), больше не принимается за подмену.
- Локация: страну определяют три IP-базы, побеждает большинство. В подсказке видно, что ответила каждая база. Адрес DoH-сервера для локации берется через эталонный DoH, а не через DNS системы.
- Сторож больше не отключает DNS при неудачах: сначала переключается на следующий сервер по стабильности (при равенстве на избранный). Пока сети нет совсем (сон, загрузка, смена Wi-Fi), сторож ждет. Если DNS сбросила другая программа, сторож возвращает подключение.
- При выключении и перезагрузке Windows подключение не снимается: DNS остается на адаптере, и после перезагрузки DNEX продолжает с того же сервера.
- После подключения DNEX проверяет помехи: включенный VPN, безопасный DNS в Chrome, Edge, Яндекс Браузере, Brave и Firefox, прокси Windows, записи в hosts, свои DNS на других адаптерах. Показывает, что отключить.
- Если при подключенном DNEX включить VPN, появляется предупреждение.
- Программа больше не закрывает соединения чужих приложений. После подключения и отключения она подсказывает перезапустить Claude и ChatGPT, если они открыты.
- Кнопки «Перепроверить» и «Проверить сейчас» стали заметнее, «Найти новые серверы» выделена как основная.
- Закрыта утечка DNS через IPv6: раньше DNS менялся только для IPv4, и часть запросов шла по IPv6 к DNS роутера. Если у сервера есть IPv6 и у компьютера есть IPv6-интернет, DNS ставится и для IPv6. Иначе на время подключения IPv6 выключается на тех адаптерах, где роутер раздает DNS по IPv6, и включается обратно при отключении.
- Для DoH-серверов программа узнает и их IPv6-адреса. Поиск находит IPv6-адреса в источниках, у IPv6-адресов определяется страна.
- Тест утечки в «Проверке подключения»: через dnscheck.tools видно, какие резолверы на самом деле отвечают. Если у них разные владельцы, показывается предупреждение.
- Новая помеха в проверке системы: DNS по IPv6 на сетевой карте или Wi-Fi, который ведет мимо DNEX.
- Над таблицей у выбранного сервера видно, откуда он взят: сайт и путь «хлебными крошками» (github.com › автор › репозиторий, 4pda.to › тема, Telegram › канал). Щелчок открывает страницу. В колонке «Источник» короткая форма.
- Внизу одна панель вместо двух: что сделано, пояснение второй строкой, «Отменить» и отсчет до исчезновения (8 секунд, под мышью отсчет стоит).
- Рамка «Лучшие по стабильности» стоит справа от проверки подключения. Отмена («Отменить», Ctrl+Z) есть у удаления, автоочистки, добавления сервера, подключения, переключения, отключения, избранного, сохранения настроек, очистки журнала и пропуска версии.

## 0.1.0

Первая публичная версия.

### Проверка серверов и сервисов

- Доступ к ChatGPT, Claude и Gemini засчитывается только по ожидаемому ответу API. Страница защиты, редирект или ошибка сервера доступом не считаются.
- Тот же критерий используется в таблице серверов и в блоке «Проверка подключения», поэтому результаты совпадают.
- Для каждого сервиса видно, через какую страну идет доступ. Если сервис открывается напрямую, страна не показывается.

### Локация

- Страна и город DNS-сервера определяются по двум IP-базам: ipinfo.io и ipwho.is. Если базы расходятся, рядом появляется предупреждение.
- Флаги стран скачиваются один раз и хранятся в кэше.

### Трей

- Меню показывает статус подключения, пинг, стабильность и доступность трех сервисов.
- Пункт «Переключить на лучший» подключает самый надежный из рабочих серверов.
- Доступность сервисов обновляется при запуске, при подключении и через заданный интервал.

### Окно

- Шапка показывает пинг, стабильность и число доступных сервисов. При узком окне эти блоки переходят на вторую строку.
- Значок связи показывает пинг столбиками: их число и цвет зависят от значения. Значок есть в шапке, в таблице и в меню трея.
- Компактный вид: отдельное окно с кнопкой подключения, статистикой и списком рабочих серверов.
- Колонки таблицы скрываются по мере сужения окна, чтобы главное не обрезалось.
- Окно настроек: эталонный DoH, таймаут, число одновременных проверок, интервалы трея и сторожа, папка данных.

### Исправления

- Подсветка кнопок и вкладок покрывает всю кнопку, а не только текст.
- Галочки центрированы.
- Тексты интерфейса приведены к единому стилю.

### Известные ограничения

- Локация определяется по IP-базам, а не по физическому месту. Для DoH-серверов за anycast-адресами она может показывать ближайший узел.
- Признаки блокировки сервисов определяются эвристически. Их можно поправить в `settings.json`.
- Встроенный каталог серверов устаревает: адреса сервисов меняются.
- Проверка работает только по IPv4.
- Программа не подписана цифровой подписью, Windows SmartScreen может показать предупреждение.
- Версии для Android пока нет. Перенос уже идет, выйдет отдельным релизом.
